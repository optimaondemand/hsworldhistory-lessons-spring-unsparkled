# HS World History (second half), plain lessons: archive

This repository is the unsparkled archive of the Spring half of Optima's Grade 9 World History course (Weeks 19-36 and the Appendix). It holds the plain lesson, primary-source and module-map pages exactly as they were before the course was sparkled, at the same paths as the live lesson repo (`hsworldhistory-lessons-spring`), and is served on GitHub Pages so the "(Unsparkled)" modules in Canvas can embed them.

- Nothing here is ever edited, renamed or force-pushed. Never copy a sparkled page into it.
- Week 19 lessons and primary sources were rebuilt from the course's plain source (the last plain versions in the live repo's history) with the course's no-numbers-in-body-text rule applied; the only differences from those originals are the removed week, module and lesson numbers.
- Created 2026-11-20.
